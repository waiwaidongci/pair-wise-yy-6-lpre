# 墨锭试磨室

墨锭建档、连续试磨、复磨判定与评分统计。零依赖，Node.js 内置 `http` 实现。

## 运行

```bash
npm start
```

访问 `http://localhost:3037`。数据保存在 `data/ink-stick-testing.json`（删除后启动会自动重建演示数据）。

## 业务流程

### 1. 建档

填写墨锭编号（唯一）、烟料来源、胶料比例、存放年限、存放位置，保存后状态为「待试磨」。

### 2. 试磨

每块墨锭可连续多轮试磨，每次提交：试磨纸张、加水量、出墨速度（慢/中/快）、墨色层次、
沉淀情况（无/少/较多/多）、评分（0–100）。复磨时在表单中选择前一次结果作为基准（默认最近一轮）。

判定规则（按优先级）：

1. **连续两轮评分低于 75** → 重点观察；
2. **评分 ≥ 85 且沉淀较基准减少** → 已试磨（首次试磨无沉淀基准，评分 ≥ 85 即通过）；
3. 其余情况 → 待复磨：沉淀未减少（持平/增多），或沉淀虽减少但评分未达 85。

评级按当轮评分：≥85 优，75–84 良，<75 差。

### 3. 查询

列表可按**状态**（待试磨/待复磨/已试磨/重点观察）、**最近一轮评级**（优/良/差）筛选，
可按建档顺序或最近试磨时间排序，并支持编号、烟料、位置关键词搜索。每张卡片按轮次顺序展示全部试磨结果及沉淀增减对比。

### 4. 统计看板

给出墨锭总数、**待复磨数量**、已试磨/重点观察/待试磨数量、试磨总次数与**所有试磨记录的平均分**。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/items` | 墨锭列表（含每轮试磨与派生信息） |
| GET | `/api/items/:idOrCode` | 墨锭详情 |
| POST | `/api/items` | 建档（编号重复返回 409） |
| POST | `/api/items/:idOrCode/tests` | 提交一轮试磨结果，返回新状态与判定说明 |
| GET | `/api/stats` | 统计看板数据 |

# 墨锭试磨室

墨锭建档、连续试磨、沉淀对比与评分统计。

运行：

```bash
npm start
```

访问 `http://localhost:3037`。数据保存在 `data/ink-stick-testing.json`（首次启动若不存在会写入示例数据）。

## 流程

1. **建档**：录入编号、烟料来源、胶料比例、存放年限、存放位置，建档后状态为「待试磨」。编号不可重复。
2. **连续试磨**：选择墨锭，再从「前一次结果」下拉中选择本次复磨要对比的基准（默认最近一次；首次试磨选「首次试磨」），填写：
   - 试磨纸张、加水量、出墨速度（快/中/慢）、墨色层次
   - 沉淀情况：无 / 少 / 中 / 多（按等级量化后与基准对比）
   - 评分：0–100
3. **状态判定**（每次提交自动完成，并写入日志）：
   - 沉淀相对所选前次结果**没有减少** → 进入「待复磨」队列
   - **评分 ≥ 85 且沉淀减少** → 记为「已试磨」（首次试磨无沉淀可比时，评分 ≥ 85 即通过）
   - **连续两次评分 < 75** → 转「重点观察」
   - 其余未达标情况 → 「待复磨」
4. **查询回看**：卡片按时间顺序保留每块墨锭的全部试磨结果，支持按状态、评级（优 ≥85 / 良 75–84 / 差 <75 / 未评）筛选，按建档顺序、最近试磨、评分高低排序，并可关键词搜索。
5. **统计看板**：给出待复磨数量、各状态数量、平均分（按每块墨锭最近一次评分计算）和累计试磨次数。

## HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/items` | 墨锭列表，支持 `status`、`grade`、`sort=created|recent|score`、`q` |
| GET | `/api/items/:id` | 墨锭详情（含完整日志） |
| POST | `/api/items` | 建档 `{code, smokeSource, glueRatio, ageYears, storage}` |
| POST | `/api/items/:id/tests` | 提交试磨结果 `{baselineSeq?, paper, water, speed, colorLayer, sediment, score}` |
| GET | `/api/stats` | 看板统计 |
